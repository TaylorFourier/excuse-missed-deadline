A deterministic program that writes one excuse an AI agent gives its human for missing a deadline. The line is the whole entry.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

The grader sets `MAKEFUN_OUTPUT_DIR=/output`. `node main.ts` writes UTF-8 text to `$MAKEFUN_OUTPUT_DIR/entry.txt` and prints the code-point count, UTF-16 length, UTF-8 byte length, and SHA-256.
